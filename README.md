# 代码转换器 · 编程学习工作台

一个**打开即用**的本地桌面工具：左边选一门语言编写代码并**真实编译运行**，右边选另一门语言**一键转换**，转换结果也可以直接运行对照——用你已经学过的语言（如 C），去对照理解另一门语言（如 Python）。

## 功能特性

- **左右双栏工作台**：左边编写/运行，右边转换/对照，两边可同时运行同一段程序，输出一致即理解正确
- **四种语言**：C、C++、Python、JavaScript，全部支持真实编译执行（gcc/g++/python/node）
- **离线规则引擎转换**：覆盖教材常见语法（`printf/scanf` ↔ `print/input`、`cin/cout` ↔ `input/print`、C/JS 的 `for` ↔ Python `range`、函数、数组、`if/while/do-while` 等），零依赖零成本
- **可选 AI 转换**：配置任意 OpenAI 兼容接口（DeepSeek / 本地 Ollama 等）即可高质量转换复杂代码
- **打开即用**：双击 `启动代码转换器.bat`，自动启动本地服务并打开浏览器；关闭窗口即退出
- **输入防呆**：检测到程序需要键盘输入（`scanf/cin/input()` 等）而「标准输入」框为空时，会提示先填写，避免空输入跑出未定义结果
- **本地安全**：服务仅监听 `127.0.0.1`，不联网、不上传任何数据；AI 配置仅保存在本机浏览器 localStorage

## 快速开始

1. 环境要求：Windows + Python 3.8+；运行 C/C++ 需安装 gcc/g++（如 MinGW、MSYS2）；运行 JS 需安装 Node.js
2. 双击 **`启动代码转换器.bat`**（或命令行执行 `python server.py`）
3. 浏览器自动打开工作台，左侧选语言写代码 → 运行；右侧选目标语言 → 规则转换/AI 转换 → 运行结果对照

## 项目结构

```
├── 启动代码转换器.bat   # 双击启动入口
├── server.py             # 本地 HTTP 服务（静态页面 + 运行/转换 API，零第三方依赖）
├── converter/
│   └── rule_engine.py    # 离线转换规则引擎（全方向语言映射 + 类型推断 + 自动头文件）
├── web/                  # 前端界面（CodeMirror 编辑器，全部本地化，无 CDN）
│   ├── index.html
│   ├── css/style.css
│   └── js/app.js
└── 测试脚本              # _selftest.py / _e2e_test.py / _api_test.py（可复现验证）
```

## 转换能力说明

规则引擎为**离线确定性转换**，对常见教材代码效果良好（变量、循环、分支、函数、数组、输入输出互转等），并自动处理：C 头文件补全、Python `if __name__ == "__main__"` 守卫、C/JS 输入辅助函数等。指针、结构体、类、异常等复杂特性建议使用 **AI 转换**。
