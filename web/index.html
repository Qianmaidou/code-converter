AI 转换设置

配置一个「OpenAI 兼容」接口后，「AI 转换」能高质量地把任意代码转换为目标语言。 推荐免费/低成本方案：DeepSeek（接口地址 https://api.deepseek.com，模型 deepseek-chat， 到 platform.deepseek.com 申请 API Key）；或本地 Ollama（接口地址 http://127.0.0.1:11434/v1， Key 随便填，模型填你拉取的模型名）。

配置仅保存在本机浏览器中，不会上传到任何服务器。API Key 仅用于请求你填写的接口。
